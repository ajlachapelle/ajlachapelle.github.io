Overview
======
[Rasterization](https://en.wikipedia.org/wiki/Rasterisation) is the old reliable method for rendering 3D geometry on pixel displays. This is an older scanline software rendering algorithm that I wrote during my undergrad studies. I used geometric and vector math fundamentals to develop a set of operations that correctly renders a set of triangles.
